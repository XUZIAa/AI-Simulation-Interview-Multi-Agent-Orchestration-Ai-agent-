## 为什么做这个

市面上多数 AI 开源面试工具的问题是**面试官会跑偏**：聊几轮就忘了自己是谁、忘了在考什么，或者一路顺着候选人的话走，问不出深度。

根因在于把实时语音模型当成了大脑。实时模型有硬性上下文限制（音频历史通常只保留百轮或几百秒），一场 30 分钟以上的面试必然被截断，人格漂移是**必然**而非偶然。

这里的做法是**双环架构**：

```
Fast Loop（口）    实时语音模型：只负责听懂 + 用人设语气说出导演给的意图
                  ↑ 有界、短、不依赖长期记忆

Slow Loop（脑）    后端权威状态机 InterviewState：
                  当前考察维度 / 已问题目 / JD 技能覆盖度 / STAR 完整度 /
                  追问深度 / 打断额度 / 技能深度阶梯 / 漂移分数
                  ↑ 单一事实来源，每轮落盘 SQLite，崩溃可恢复
```

人格不是"被记住"的，而是**每轮重新注入**的。所以在架构上不存在"忘了自己是谁"。


### 真题补充

题库在模型出题之外，会追加一批高频真题。频次来自多篇面经的交叉统计，所以问出来的更接近真实考察重点，而不是模型凭印象编的分布。

这部分**只对 Java 后端与 Agent 方向生效**。

模型出的项目题与 JD 题不受影响，真题只作为基础题追加，不占用它们的配额。

### 硬时间闸门

10 / 20 / 30 / 45 分钟四档预设。到点**强制进入收尾**，不给模型自由裁量的机会。不足 5 分钟不生成完整复盘。


### 防漂移三道防线

1. **人设契约** — 结构化定义编译成运行时指令
2. **输出守卫** — 正则前置加小模型复核，拦截"作为 AI 助手""我无法提供"这类越界
3. **心跳重锚** — 每若干轮或漂移抬头时，强制重灌人设与状态摘要

## 使用教程

### 1. 安装

到 release 下载安装包，双击安装即可。首次启动会初始化本地数据库，需要几秒。

### 2. 配置模型（必须）

程序本身不含任何模型，需要你自己的 API Key。打开**设置**，在 **API Key** 页填写。

这个阿里云百炼能免费用 亲测能用很久 .但是推荐用chatgpt,claude。

> 强烈建议戴耳机。

### 3. 准备面试

**准备面试**页是四步向导：

1. **简历** — 上传 PDF / DOCX / TXT，或选之前传过的
2. **目标岗位** —
3. **差距诊断**（可跳过）
4. **面试设置** —

点「开始面试」，出题约需一分钟。

### 4. 面试中

进去就是沉浸界面，直接开口说话即可。

| 操作 | 说明 |
| --- | --- |
| 打断面试官 | 直接开口，或点底部闪电图标 |
| 求助提词 | 卡壳时点「求助提词」，给关键词和展开方向 |
| 提词器 | 右侧面板，可以随时关掉 |
| 代码沙盒 | 点代码图标展开。可以让它出一道题，写完能**直接运行**和跑用例 |
| 摄像头 | 可开可关，画面只在本机渲染 |
| 结束面试 | 点两次确认 |

代码沙盒支持 Python 和 JavaScript。Python 用程序自带的运行时，JavaScript 需要你机器上装了 Node。后续有人会加入更多。

### 5. 复盘

面试满 5 分钟会自动生成复盘：多维雷达图、逐字稿高亮批注、满分答案重构、韵律分析（语速、停顿、填充词，规则算的不是模型猜的）、专项提升方案。

错题会自动汇进**错题本**，历次分数走势在**成长轨迹**里看。



## 技术栈

| 层 | 选型 |
| --- | --- |
| 桌面外壳 | Tauri 2（Rust） |
| 前端 | React 19 + Vite 7 + TypeScript + Tailwind 4 + shadcn/ui |
| 图表与编辑器 | Recharts、CodeMirror 6 |
| 后端 | Python 3.12，FastAPI，以 sidecar 子进程运行 |
| 数据 | SQLAlchemy 2.0 async + aiosqlite（WAL） |
| 实时语音 | WebSocket，OpenAI Realtime 风格协议 |
| 音频 | sounddevice + numpy（16 kHz 采集 / 24 kHz 播放） |
| 文档解析 | pdfplumber、python-docx |
| 打包 | PyInstaller + Tauri NSIS |

## 隐私

- 所有数据存本地 SQLite（`%LOCALAPPDATA%/Interviewer/`），不上传
- API Key 存 Windows 凭据管理器，不写进配置文件
- 摄像头画面仅本地渲染，不经网络
- 音频需要发送到语音服务商才能对话，这是功能必需
- 简历含个人信息，请自行评估后再上传
