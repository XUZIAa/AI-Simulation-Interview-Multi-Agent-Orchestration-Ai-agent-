## 为什么做这个

市面上多数 AI 开源面试工具的问题是**面试官会跑偏**：聊几轮就忘了自己是谁、忘了在考什么，或者一路顺着候选人的话走，问不出深度。

根因在于把实时语音模型当成了大脑。实时模型有硬性上下文限制（音频历史通常只保留百轮或几百秒），一场 30 分钟以上的面试必然被截断，人格漂移是**必然**而非偶然。

这里的做法是**双环架构**：

```
Fast Loop（口）    实时语音模型：只负责听懂 + 用人设语气说出导演给的意图
                  ↑ 有界、短、不依赖长期记忆

Slow Loop（脑）    后端权威状态机 InterviewState：
                  当前考察维度 / 已问题目 / JD 技能覆盖度 / STAR 完整度 /
                  追问深度 / 打断额度 / 技能深度阶梯 / 漂移分数
                  ↑ 单一事实来源，每轮落盘 SQLite，崩溃可恢复
```

人格不是"被记住"的，而是**每轮重新注入**的。所以在架构上不存在"忘了自己是谁"。

## 核心设计

### 题库约束出题

面试前由 JD 加简历生成结构化题库（技能点、领域、深度等级、来源、关联项目、预设追问路径）。导演**只能从题库中选题**，不能自由生成。这保证每个问题都对得上 JD 要求和你的真实项目经历。

### 确定性深度阶梯

答得好不好由导演评估，但**推进方向由确定性代码决定**，不交给模型：

| 回答质量 | 动作 |
| --- | --- |
| ≥ 0.65 | 深入一层（概念 → 实践 → 细节 → 极限） |
| 0.40 – 0.65 | 同层换角度再追一次 |
| < 0.40（连续两次） | 放弃深挖、换领域，并在复盘中记低分 |

这复刻了真实面试官的行为：你确实答不上来，面试官不会一直折磨你，但分数会体现出来。

### 真题补充

题库在模型出题之外，会追加一批高频真题。频次来自多篇面经的交叉统计，所以问出来的更接近真实考察重点，而不是模型凭印象编的分布。

这部分**只对 Java 后端与 Agent 方向生效**。岗位方向不在覆盖范围内时（运维、测试、算法、前端、嵌入式等）自动不启用，题库与没有这项功能时完全一致 —— 宁可不加，也不把开发视角的题塞给运维岗。

模型出的项目题与 JD 题不受影响，真题只作为基础题追加，不占用它们的配额。

### 硬时间闸门

10 / 20 / 30 / 45 分钟四档预设。到点**强制进入收尾**，不给模型自由裁量的机会。不足 5 分钟不生成完整复盘。

### 人设契约

面试官人设是结构化 JSON 而非自由文本提示词 —— 中英夹杂比例、打断倾向、攻击性、发散强度、追问深度、项目侧重、禁忌话题等十余个维度可调，可校验、可版本化、可分享。

内置人设覆盖大厂 / 中厂 / 创业 / 制造业 / 国企 / 外企 / 金融等公司画像。后续有人会加入更多。公司画像会同时影响出题倾向、评分权重与 JD 生成风格。

### 三层记忆

| 层级 | 内容 | 生命周期 |
| --- | --- | --- |
| 一次性 | 守卫检测、提词、STAR 判定、代码追问 | 单次调用后丢弃 |
| 会话级 | InterviewState、逐字稿、题目记录 | 落盘 SQLite，永不丢失 |
| 跨会话 | 错题本、成长轨迹、岗位库、简历库 | 长期累积 |

### 防漂移三道防线

1. **人设契约** — 结构化定义编译成运行时指令
2. **输出守卫** — 正则前置加小模型复核，拦截"作为 AI 助手""我无法提供"这类越界
3. **心跳重锚** — 每若干轮或漂移抬头时，强制重灌人设与状态摘要

另外在协议层收回了发言授权：服务端 VAD 默认会自动生成回复，那会绕过导演让模型自由发言。这里关闭了自动回复，未授权的回复会被立即取消。

## 使用教程

### 1. 安装

到 [Releases](https://github.com/XUZIAa/AI-Simulation-Interview-Multi-Agent-Orchestration-Ai-agent-/releases) 下载安装包，双击安装即可。首次启动会初始化本地数据库，需要几秒。

Windows 可能提示"未知发布者"，这是因为安装包没有做代码签名（个人项目，证书要年费）。点"更多信息"再"仍要运行"。

### 2. 配置模型（必须）

程序本身不含任何模型，需要你自己的 API Key。打开**设置**，在 **API Key** 页填写。

这个阿里云百炼能免费用 亲测能用很久 
**最省事**：只注册阿里云百炼一个 Key。实时语音必须来自这里，同时它也能供四个文本角色使用。

**效果最好**：百炼 + DeepSeek 两个 Key。

| 角色 | 推荐 | 理由 |
| --- | --- | --- |
| 实时语音 | 百炼 `qwen3-omni-flash-realtime` | 语义 VAD 能区分"嗯嗯"附和与真插话，这对打断体验是决定性的；多音色让不同人设听得出区别 |
| 导演 / 复盘 | DeepSeek `deepseek-chat` | 长上下文、成本低，复盘质量更好 |
| 提词 / 守卫 | 百炼 `qwen-flash` | 这两个角色在延迟敏感链路上，要快 |

每个 Key 右边有「获取」直接跳到对应控制台，填完点「测试」验证可用。Key 存入 Windows 凭据管理器，不写进配置文件。

然后在**模型**页按角色绑定，**实时语音**页选音色，**音频**页选麦克风和播放设备。

> 强烈建议戴耳机。外放时回声门控会一直工作，但物理隔离更可靠。

### 3. 准备面试

**准备面试**页是四步向导：

1. **简历** — 上传 PDF / DOCX / TXT，或选之前传过的
2. **目标岗位** — 上传 JD 文件、粘贴 JD 原文，或者只填一个岗位名让它按公司类型和级别生成一份
3. **差距诊断**（可跳过）— 把简历和 JD 摆一起比对，指出缺哪些硬性要求，并给出面试时用现有经历弥补的话术
4. **面试设置** — 选面试官人设、时长，决定要不要代码环节

点「开始面试」，出题约需一分钟。

### 4. 面试中

进去就是沉浸界面，直接开口说话即可。

| 操作 | 说明 |
| --- | --- |
| 打断面试官 | 直接开口，或点底部闪电图标 |
| 求助提词 | 卡壳时点「求助提词」，给关键词和展开方向 |
| 提词器 | 右侧面板，可以随时关掉 |
| 代码沙盒 | 点代码图标展开。可以让它出一道题，写完能**直接运行**和跑用例 |
| 摄像头 | 可开可关，画面只在本机渲染 |
| 结束面试 | 点两次确认 |

代码沙盒支持 Python 和 JavaScript。Python 用程序自带的运行时，JavaScript 需要你机器上装了 Node。后续有人会加入更多。

### 5. 复盘

面试满 5 分钟会自动生成复盘：多维雷达图、逐字稿高亮批注、满分答案重构、韵律分析（语速、停顿、填充词，规则算的不是模型猜的）、专项提升方案。

错题会自动汇进**错题本**，历次分数走势在**成长轨迹**里看。

## 技术栈

| 层 | 选型 |
| --- | --- |
| 桌面外壳 | Tauri 2（Rust） |
| 前端 | React 19 + Vite 7 + TypeScript + Tailwind 4 + shadcn/ui |
| 图表与编辑器 | Recharts、CodeMirror 6 |
| 后端 | Python 3.12，FastAPI，以 sidecar 子进程运行 |
| 数据 | SQLAlchemy 2.0 async + aiosqlite（WAL） |
| 实时语音 | WebSocket，OpenAI Realtime 风格协议 |
| 音频 | sounddevice + numpy（16 kHz 采集 / 24 kHz 播放） |
| 文档解析 | pdfplumber、python-docx |
| 密钥 | 系统 keyring（不落明文） |
| 打包 | PyInstaller + Tauri NSIS |

前后端之间是本机 HTTP 加 WebSocket，41 条路由与 20 类事件。

后端分层：`core`（配置/事件/类型）→ `domain`（领域模型）→ `data`（持久层）→ `llm`（供应商抽象）→ `realtime`（语音链路）→ `agents`（各职能 Agent）→ `orchestration`（编排引擎）→ `rpc`（本机接口）。

## 从源码运行

需要 Python 3.12+、[uv](https://docs.astral.sh/uv/)、Node 20+、Rust 工具链。

```bash
# 后端依赖
uv sync

# 前端依赖
cd desktop
npm install

# 开发模式（会同时拉起后端）
npm run tauri dev
```

打包完整安装包分两步：

```bash
# 1. 后端打成 sidecar
uv run pyinstaller interviewer-backend.spec --noconfirm

# 2. 前端与安装包
cd desktop
npm run tauri build
```

产物在 `desktop/src-tauri/target/release/bundle/nsis/`。

> 后端可执行文件名必须是 ASCII。中文文件名会让 PyInstaller 引导器在 CRT 层触发 `0xC0000409` 崩溃（目录名含中文没问题）。

改动后端的数据模型后要重新生成前端类型：

```bash
cd desktop && npm run gen:types
```
